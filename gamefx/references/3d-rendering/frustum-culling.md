# Frustum Culling：视锥剔除

## 目标

用相机的投影矩阵和视图矩阵构造视锥，对世界包围体做相交测试，跳过完全位于视锥外对象的绘制和昂贵更新。视锥剔除不处理被其他物体遮挡的对象，后者属于遮挡剔除。

## 核心规则

```text
frustum = extractPlanes(projection * view)
for object in scene:
  visible = frustum.intersects(object.worldBounds)
  if visible:
    updateExpensiveVisuals(object)
    draw(object)
```

- 使用世界空间包围球或包围盒，不使用单独的物体原点。
- 动画、蒙皮或程序化几何改变尺寸后，更新保守包围体。
- 矩阵顺序、左右手坐标和裁剪空间约定必须遵循当前引擎。

## 动效分镜

1. 用俯视或斜俯视展示相机和一组分布广泛的物体。
2. 绘制半透明青色视锥和边线，让相机平滑转动。
3. 相交物体显示为实体并高亮；完全在外面的物体在教学层显示为暗色线框。
4. 实时显示 `drawn / total` 数量。教学线框只是调试可视化，正式渲染路径必须真正跳过外部对象。
5. 可增加一个原点已出屏、但网格仍部分可见的大物体，验证包围体测试。

## 实现要求

- 优先复用引擎的相机视锥和包围体 API，避免重复实现矩阵平面提取。
- 对完全不可见对象跳过昂贵动画更新时，确保重新可见后能恢复正确状态；模拟状态不能无条件停更。
- 调试绘制不能改变正式可见性结果，也不能把被剔除对象重新提交给正常渲染通道。

## 常见错误

- 只测试原点，导致部分可见的大物体被错误剔除。
- 使用过期或局部空间的包围体。
- 把视锥剔除误当成遮挡剔除。
- 为演示而继续绘制所有对象，却声称已经节省 GPU 绘制。

## 验收

- 相机转动时，绘制计数与真实提交绘制的对象一致。
- 完全在外部的对象被剔除，部分相交对象保留。
- 动画变形后的包围体仍覆盖整个网格。
- 外部对象恢复可见时没有错误状态；已停更的非必要视觉更新能正确恢复。
