# Level of Detail：细节层次

## 目标

相机远离物体时切换到更便宜的网格，在保留可识别轮廓的前提下减少三角形、动画和 CPU 更新成本。

## 核心规则

- 准备高、中、低三档网格。生产默认可从约 `100%`、`30%`、`10%` 三角形数量开始，再按屏幕投影尺寸和轮廓调整。
- 教学演示可使用 `1280 → 80 → 20` 三角形，让差异足够明显。
- 每帧或按项目既有频率计算相机距离，选择对应档位，只显示当前网格。
- 阈值加入约 `10%` 的滞回带：远离时越过 `threshold * 1.1` 才降级，靠近时回到 `threshold * 0.9` 才升级。多档位须保持相邻区间一致。

```text
if distance > farThreshold + margin: level = LOW
else if distance < farThreshold - margin: level = MEDIUM
setVisibleMesh(level)
```

实际实现应根据当前档位处理所有相邻阈值，不能只处理一条边界。

## 动效分镜

1. 让同一个物体沿相机前后方向平滑移动，并缓慢旋转以展示轮廓。
2. 地面标记 LOD 切换距离，标签实时显示距离、档位和三角形数。
3. 高、中、低网格共用位置、旋转和材质语义，仅细节程度改变。
4. 使用线框叠加展示拓扑差异；切换时保持物体锚点一致。
5. 可提供暂停和手动距离控制，便于观察滞回区间。

## 实现要求

- 优先复用项目引擎的 LOD 组件；自行实现时，距离和矩阵使用同一空间。
- 隐藏的高细节网格不应继续运行昂贵的动画或 CPU 更新。
- 检查阴影轮廓和各向异性材质；必要时让阴影使用独立档位。
- 有明显跳变时再考虑淡变或抖动过渡，不要用过渡掩盖错误的档位选择。

## 常见错误

- 阈值没有滞回，物体在边界附近闪烁。
- 各档枢轴、比例或轮廓差异过大，产生明显跳变。
- 只降低渲染成本，却让隐藏网格继续完整更新。
- 只按世界距离设置阈值，忽略 FOV、屏幕尺寸和物体实际投影大小。

## 验收

- 远离和靠近分别选择正确档位，任一时刻只有目标网格参与渲染。
- 在阈值附近往返不会逐帧来回切换。
- 各档共享变换与锚点，距离和三角形统计真实更新。
- 隐藏档位的昂贵更新确实停止，阴影没有不可接受的跳变。
