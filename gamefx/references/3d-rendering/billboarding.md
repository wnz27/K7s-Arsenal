# Billboarding：公告牌

## 目标

让血条、名字、伤害数字或远景精灵始终面向相机。根据用途选择完整面向相机或只绕世界上方向转动的竖直公告牌。

## 核心规则

完整公告牌：

```text
label.worldRotation = camera.worldRotation
```

竖直公告牌：

```text
direction = camera.position - tree.position
direction = projectOnPlane(direction, worldUp)
tree.lookAlong(normalize(direction))
```

- 复制的是世界空间朝向；父子变换不同，不能直接照搬局部旋转。
- 四元数方案等价于复制相机世界四元数，但需匹配平面的正反方向。
- 竖直模式把方向投影到地面，保持世界上方向不变；相机正上方导致方向接近零时保留上一有效朝向。
- 贴图需要透明边缘时使用正确混合和双面设置，同时控制 overdraw。

## 动效分镜

1. 放置两个角色：左侧血条固定在角色局部，右侧血条使用公告牌。
2. 两个角色同步转动，相机再缓慢绕场景摆动，提供不同观察角度。
3. 左侧血条逐渐侧转、变窄或镜像；右侧始终完整可读。
4. 显示 `plain quad` 与 `billboard` 标签，血条内容保持不变。
5. 可提供树木或远景精灵作为竖直模式，确保其不会随相机俯仰倾倒。

## 实现要求

- 每帧在相机世界矩阵更新后计算公告牌，避免使用上一帧相机朝向。
- 使用引擎的 billboard 或 sprite 组件时，确认其模式、Up 轴和父节点行为。
- 屏幕固定尺寸的 UI 与世界空间公告牌分开处理；需要恒定的屏幕可读尺寸时再按深度调整比例。
- 文字和血条不得因为相机绕到背面而镜像。

## 常见错误

- 把相机世界旋转直接写给有变换父节点的局部旋转。
- 所有对象都使用完整模式，导致树木随相机俯仰倾斜。
- 忽略平面自身的 forward 轴和材质正反面。
- 相机与竖直投影方向共线时归一化零向量。

## 验收

- 任意方位角下血条和名字保持正面、可读且不镜像。
- 竖直公告牌只绕世界 Up 轴旋转，不发生意外俯仰。
- 带旋转、缩放父节点时仍保持正确世界朝向。
- 相机位于正上方等退化位置时不会出现 NaN 或突然翻转到无效方向。
