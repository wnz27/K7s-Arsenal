# Quaternions：四元数旋转

## 目标

用四元数保存和组合 3D 朝向，用球面线性插值 `slerp` 在起止朝向之间走短弧，避免逐分量插值欧拉角造成额外翻转和不稳定速度。

## 核心规则

```text
a = normalize(startRotation)
b = normalize(targetRotation)
if dot(a, b) < 0: b = -b
rotation = slerp(a, b, clamp(elapsed / duration, 0, 1))
```

- 四元数乘法有顺序，组合旋转时遵循引擎的世界或局部变换约定。
- `q` 与 `-q` 表示同一朝向；点积为负时翻转其中一个，以选择短弧。
- 长时间累乘后归一化，修正数值漂移。
- 四个分量不是四个独立角度；欧拉角仅用于编辑器输入或显示。

## 动效分镜

1. 左右放置两个相同飞行器，使用完全相同的起止朝向和时长。
2. 左侧逐分量插值欧拉角，右侧使用四元数短弧 `slerp`，这是唯一机制差异。
3. 对机鼻方向采样并留下轨迹，直观显示左侧绕行、右侧短弧。
4. 到达终点后停留，再返回起点；往返使用相同规则。
5. 显示两条路径的累计转角。参考演示可用欧拉角 `(-130°, -50°, 130°)` 到 `(180°, 70°, -120°)` 制造约 `371°` 对 `143°` 的明显对照，但这些数值不是通用常数。

## 插值与节奏

- `t = clamp(elapsed / duration, 0, 1)` 直接传给 `slerp` 可得到恒定角速度。
- 需要缓入缓出时，先对 `t` 使用明确的 easing，例如 `smoothstep`，此时不再声称恒定速度。
- 轨迹按进度或固定时间采样，避免帧率改变轨迹密度和形状。

## 常见错误

- 未处理负点积，选了长弧。
- 把四元数分量当角度分别插值。
- 忽视乘法顺序、坐标空间或矩阵变换约定。
- 用逐帧随机或逐帧增量构造轨迹，导致不同帧率结果不同。

## 验收

- 两种方式都准确到达同一组起止朝向，右侧路径为短弧。
- 四元数保持单位长度，往返后无持续漂移或跳变。
- 改变帧率只改变采样平滑度，不改变最终轨迹和总时长。
- 欧拉对照组与四元数组除插值方法外，模型、相机、时间和轨迹采样完全一致。
