# Easing：缓动

## 目标

把线性时间进度映射为曲线进度，用于起点、终点和时长都明确的 UI 移动、镜头切换和短动画。目标持续移动或需要物理响应时，改用速度控制器。

## 核心公式

```text
t = clamp(elapsed / duration, 0, 1)
easeOutCubic = 1 - pow(1 - t, 3)
value = start + (target - start) * easeOutCubic
```

可同时提供 `linear`、`easeInOutCubic` 和 `easeOutBack`。UI 移动可从约 `0.3 s` 开始；需要轻微过冲时使用 back 类曲线，但不要让有硬边界的数值越界。

## 动效分镜

1. 左侧绘制多条「时间—数值」曲线，右侧让方块沿各自曲线同时移动。
2. 每条轨道共享约 `1.5 s` 的教学时长和起止点，用竖线标记当前时间。
3. 在曲线和移动轨道上同步显示当前值，过冲曲线允许越过终点再回落。
4. 到达终点后短暂停留，再统一重播。

## 实现要求

- 保存固定的起点、终点和开始时间，不要每帧把当前位置改成新起点。
- 使用绝对经过时间求进度，而不是逐帧累加固定比例。
- 重用项目已有 tween 或动画系统，并正确取消、完成和回收。

## 常见错误

- 每帧更新起点，实际变成另一种指数趋近。
- 对透明度、索引等有界值使用会过冲的曲线。
- 每条轨道使用不同终点或时长，导致比较失真。
- 用缓动处理需要持续响应速度或碰撞的运动。

## 验收

- `t = 0` 和 `t = 1` 时分别到达预期起止值，back 曲线中间过冲属于预期。
- 曲线图与对象位置来自同一个函数和同一个时间进度。
- 改变渲染帧率不改变总时长和轨迹。
- 重播、取消和完成后没有残留状态或重复更新。
