# Screen Shake：屏幕震动

## 目标

用短暂、衰减的相机视觉偏移表达命中强度。震动不能修改相机的持久跟随位置，也不能改变游戏瞄准、碰撞或射线查询所使用的逻辑位姿。

## 核心规则

```text
trauma = clamp(trauma + impact, 0, 1)
trauma = max(0, trauma - decay * dt)
amplitude = trauma * trauma
offsetX = smoothNoise(time * frequency, seedX) * maxOffset * amplitude
```

- 每次命中可增加约 `0.3–0.6` trauma，并限制在 `[0, 1]`。
- 衰减可从每秒 `1` 开始；X、Y 和 roll 共用强度，但使用不同噪声种子。
- 每帧从稳定基础相机位姿重新计算偏移，不能把偏移累加进基础位置。
- 提供震动强度设置，并尊重项目的减少动态效果选项。

## 动效分镜

1. 两个相同场景同时受到轻击、轻击和重击，共享命中时间与冲击环。
2. 左侧用每帧随机数乘原始 trauma，右侧用连续噪声乘 `trauma²`。
3. 显示 trauma 与 `trauma²` 两条强度条，让轻重击差异可见。
4. 支持点击触发命中；震动期间场景在裁剪区域内平移和轻微旋转。

## 常见错误

- 每帧重新随机造成刺眼抖动，或使用原始 trauma 让轻击过强。
- 把震动写回逻辑相机，导致瞄准和跟随漂移。
- 使用全局时间缩放实现震动，干扰其他系统。
- 缺少关闭或降低震动的设置。

## 验收

- 重击明显强于轻击，衰减结束后相机精确回到稳定基础位姿。
- 噪声连续，偏移不随帧率改变平均速度或累计漂移。
- 逻辑射线、碰撞和跟随目标不受视觉偏移影响。
- 降低强度或关闭震动后，其余命中反馈仍正常工作。
