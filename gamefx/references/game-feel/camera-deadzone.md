# Camera Deadzone：相机死区

## 目标

让玩家在屏幕中央一个区域内移动时相机保持不动，只有越过边缘才移动相机。小幅移动和来回转身因此不会持续带动画面。

## 核心规则

```text
offset = player.position - camera.position
excess.x = offset.x - clamp(offset.x, -halfWidth, halfWidth)
excess.y = offset.y - clamp(offset.y, -halfHeight, halfHeight)
camera.position += excess
```

死区可从约四分之一屏幕宽开始，最终相机目标还须限制在关卡边界内。

## 动效分镜

1. 玩家在水平场景中往返移动，屏幕中央绘制固定大小的矩形死区。
2. 玩家处于死区内时，背景与相机位置保持不变。
3. 玩家越过边缘后，相机只补偿超出部分，让玩家停留在对应边缘。
4. 显示 `camera still / following`、相机坐标和当前原因；可加平滑，但目标死区仍须清晰。

## 实现要求

- 先计算理想相机目标，再做平滑和边界限制，区分目标位置与实际位置。
- 死区以屏幕或视图空间定义时，正确转换玩家世界坐标。
- 世界边界、宽高比和窗口尺寸变化后重新计算有效范围。
- 可选前瞻偏移应独立于死区补偿，避免相互振荡。

## 常见错误

- 玩家在区域内也持续居中，失去死区作用。
- 平滑后的实际位置被用于下一轮死区判断，引起边缘振荡。
- 忘记关卡边界或混淆 X、Y 半尺寸。
- 相机震动被写入死区计算，导致跟随漂移。

## 验收

- 死区内移动时相机完全不动，越界后玩家被保持在边缘。
- 反向移动和边缘附近往返不会持续抖动。
- 关卡两端不会出现超出世界边界的视野。
- 调整窗口、缩放和震动后，死区行为仍符合坐标约定。
