# Squash and Stretch：挤压与拉伸

## 目标

通过视觉形变强调速度和落地冲击。快速运动时沿运动方向拉伸，落地时短暂压扁，再平滑恢复；默认不改变碰撞体或物理轨迹。

## 核心规则

```text
stretch = 1.3
visual.scaleY = stretch
visual.scaleX = 1 / stretch
```

- 拉伸可从约 `1.3` 开始，落地压扁可从 `0.7` 开始，并在约 `0.15 s` 内恢复。
- 2D 中另一轴使用倒数保持面积；3D 需要在另外两个轴补偿体积。
- 枢轴放在脚底或接触点，避免压扁时陷入地面或滑动。
- 形变只挂视觉节点，除非设计要求改变碰撞，否则物理形状保持独立。

## 动效分镜

1. 两个球共享相同重力、起跳位置和落点，左侧保持刚性，右侧发生形变。
2. 下落越快，纵向拉伸越明显；着地时快速转为横向压扁。
3. 显示实时 `scaleX / scaleY`，并用随高度变化的椭圆阴影辅助表达距离。
4. 恢复后短暂停留并重播，确保两组只有视觉形变不同。

## 常见错误

- 两轴同时放大或缩小，变成整体缩放而非挤压拉伸。
- 枢轴位于中心，导致角色落地时穿过地面。
- 视觉缩放意外影响碰撞、伤害范围或子节点布局。
- 每帧按固定比例恢复，效果随帧率变化。

## 验收

- 对照组与实验组的位置、落地时刻和反弹轨迹一致。
- 2D 两轴比例互为倒数，落地接触点稳定不滑动。
- 形变在指定时间内回到 `1`，碰撞查询不受视觉缩放影响。
- 不同帧率下拉伸强度、落地窗口和恢复时长一致。
