# Coyote Time：土狼时间

## 目标

角色离开平台边缘后，在约 `0.1–0.15 s` 的宽限期内仍允许起跳，容纳玩家稍晚的跳跃输入。它处理「晚按」，输入缓冲处理「早按」，两者分开实现。

## 核心规则

```text
if grounded and not jumping: grace = 0.12
else: grace = max(0, grace - dt)
if jumpPressed and grace > 0:
  velocity.y = jumpSpeed
  grace = 0
  grounded = false
```

- 使用离开实际地面的时间，不要依赖上一帧已过期的 grounded 状态。
- 起跳后立即消费宽限期，防止同一次离地触发第二次跳跃。
- 只有真实落地才能重新填充；起跳帧不能因旧碰撞状态再次填充。

## 动效分镜

1. 两名角色以相同速度跑向相同缺口，并在离地后同一时刻按下跳跃。
2. 对照组没有宽限期，按键被忽略并坠落；实验组可用约 `120 ms`，成功起跳。
3. 在平台边缘后显示宽限区域、跳跃按键标记和倒计时。
4. 落地或失败结果明确显示，随后重置并重复。

## 常见错误

- 起跳后没有清零宽限期。
- 起跳帧立即用旧 grounded 状态重新填充。
- 与输入缓冲共用一个含义模糊的计时器。
- 允许已主动跳起、处于特殊状态的角色再次使用离地宽限。

## 验收

- 宽限期内晚按可以跳，超过窗口不能跳。
- 每次离地最多触发一次宽限跳跃，真实落地后才恢复。
- 主动起跳不会重新获得宽限期。
- 对照演示中两名角色的输入时刻、速度和关卡完全一致。
