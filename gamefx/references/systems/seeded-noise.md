# Seeded Noise：种子噪声

## 目标

用种子随机数生成器和连续噪声重建一致的世界。同一种子和同一算法版本产生相同地形，相邻坐标获得相关值，而非彼此完全独立的随机高度。

## 核心规则

```text
height = 0
frequency = baseFrequency
amplitude = 1
for octave in range(4):
  height += noise(seed, x * frequency) * amplitude
  frequency *= 2
  amplitude *= 0.5
height /= amplitudeSum
```

- 可使用 `mulberry32` 等确定性 PRNG 初始化噪声表，或使用项目已有 Perlin、simplex、value noise。
- 使用 `3–5` 个 octave，每层频率约翻倍、振幅约减半，最后按振幅和归一化。
- 世界生成中避免使用无种子的 `Math.random` 或系统熵源。
- 优先按坐标采样，避免共享顺序随机流因新增一次调用而移动整个世界；存档同时记录算法或生成器版本。

## 动效分镜

1. 两条地形带各使用 `64` 列，上方逐列无种子随机，下方使用包含 4 个 octave 的平滑噪声。
2. 定期循环「相同种子」和「新种子」，重绘前保留上一地形虚线轮廓。
3. 相同种子时新地形精确覆盖旧轮廓，新种子时地形改变；上方每次都随机改变。
4. 显示种子和比较结果，使用扫描线或插值表现重绘过程，但不能掩盖最终数据差异。

## 常见错误

- 把种子只用于部分系统，其他生成步骤仍调用全局随机。
- 更换算法、采样顺序或坐标映射，却期待旧存档完全重建。
- 不归一化多 octave 总和，导致高度范围变化。
- 把独立随机样本当作连续噪声。

## 验收

- 同种子、同版本和同坐标生成逐值一致的结果，新种子产生不同结果。
- 相邻样本连续，octave 参数改变时频率和振幅符合配置。
- 新增无关随机调用不会改变按坐标生成的其他区域。
- 演示中的数据数组真正重建，虚线轮廓和一致性结论来自实际比较。
