# Tunneling：隧穿

## 目标

防止高速物体在一次物理更新中从薄墙一侧跨到另一侧，而端点重叠检测从未看到接触。对完整运动路径执行扫掠检测，或使用足够小的物理子步。

## 核心规则

```text
next = position + velocity * dt
hit = sweepShape(shape, position, next)
if hit:
  position = hit.safePosition
  resolveImpact(hit)
else:
  position = next
```

- 点状弹丸可用 raycast，有体积的物体使用 sphere、capsule 或对应 shape sweep。
- 高速刚体优先开启引擎的连续碰撞检测，并确认目标碰撞体也符合要求。
- 子步方案应让单步位移小于物体尺寸的一半左右，再按速度和最小障碍厚度验证。
- 命中后使用安全位置、法线和剩余时间处理反弹或停止，避免陷入墙面。

## 动效分镜

1. 两条通道使用相同高速弹丸和薄墙，以慢动作展示每个物理采样点。
2. 上方只检查每个端点的重叠，弹丸从墙前跳到墙后并穿过。
3. 下方检查相邻点之间的完整线段或形状扫掠，在墙面处停止并显示冲击。
4. 标出采样点序号和检测路径；参考场景可用约 `40 px` 每步对 `6 px` 墙，但实际项目按尺度换算。

## 常见错误

- 提高渲染 FPS，却让物理仍以低频端点检测运行。
- 用射线代替有体积物体，忽略弹丸半径。
- 命中后仍写到完整终点，或没有处理剩余运动。
- 只测试静止墙，忽略相对高速运动的其他物体。

## 验收

- 弹丸跨越墙面的任意步长都能被扫掠检测阻止，不会穿墙。
- 未碰撞时准确到达终点，碰撞时停在安全位置并只处理一次冲击。
- 有体积形状、斜向运动和不同帧率均通过对应场景。
- 对照演示共享运动序列，仅碰撞查询范围不同。
