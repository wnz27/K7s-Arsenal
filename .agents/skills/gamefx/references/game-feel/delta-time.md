# Delta Time：帧间隔时间

## 目标

用上一帧经过的秒数驱动移动、冷却和动画，让游戏速度不随帧率改变。速度单位是世界单位每秒，位移才是速度乘 `dt`。

## 核心规则

```text
dt = min(frameSeconds, 0.05)
position += velocity * dt
cooldown = max(0, cooldown - dt)
blend = 1 - exp(-smoothing * dt)
```

- 移动和计时只乘一次 `dt`，不要重复应用。
- 指数平滑使用 `1 - exp(-k * dt)`，不要把固定 `lerp` 系数当作帧率无关。
- 普通视觉更新可限制超长帧，避免瞬移；必须完整计算时间的模拟应使用固定步长累加器，因为截断会丢弃时间。

## 动效分镜

1. 两个赛车使用相同标称速度，上方每帧加固定距离，下方使用 `velocity * dt`。
2. 模拟帧率从 `60 fps` 平滑降到约 `14 fps`，同时显示帧率条和经过时间。
3. 低帧率期间上方逐渐落后，下方保持目标进度；显示终点和差距百分比。
4. 一轮结束后短暂停留再重置，两组除时间计算外共享赛道和速度。

## 常见错误

- 同一速度被多次乘以 `dt`。
- 只用固定每帧位移，或把毫秒直接当秒使用。
- 动画、冷却和输入计时采用不同时间口径。
- 把 `dt` 截断用于必须保留全部时间的物理模拟。

## 验收

- 相同真实时长后，30、60、144 fps 下位移和冷却结果在允许误差内一致。
- 平滑参数不随帧率改变，超长帧不会导致视觉对象瞬移。
- 演示中的低帧率来自真实更新调度，不只是修改文字。
- 对照组仅时间模型不同，赛道、标称速度和起止条件一致。
