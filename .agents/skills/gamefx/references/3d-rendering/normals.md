# Normals：法线

## 目标

用单位法线表达表面朝向，并把同一向量用于光照、反弹、贴花方向和可行走坡度判断。所有参与点积的向量必须位于同一坐标空间。

## 核心公式

```text
normal = normalize(hit.worldNormal)
walkable = dot(normal, worldUp) >= cos(maxSlopeAngle)
bounce = velocity - 2 * dot(velocity, normal) * normal
diffuse = max(0, dot(normal, normalize(lightPosition - surfacePosition)))
```

默认可行走阈值可用 `dot(normal, worldUp) >= 0.7`，约为 `45°`。更准确的实现使用 `cos(maxSlopeAngle)`。

## 动效分镜

1. 使用低面数、平直着色的网格，让每个面的朝向清晰可读。
2. 从面中心绘制短法线；网格持续缓慢旋转，灯泡绕场景运动。
3. 每帧把面中心和法线转换到世界空间，再计算面向光源的程度。
4. 面向光源的法线和表面变亮，背光面保持暗色；显示光源位置。
5. 可附加一个反弹或坡度指示器，但不要让附加演示改变主光照对照。

## 实现要求

- 面法线可由两条边的叉积计算，注意顶点环绕顺序。
- 非均匀缩放下，用法线矩阵，即模型矩阵的逆转置来变换法线，随后再次归一化。
- 插值后的顶点法线在使用前重新归一化。
- 点积光照只描述漫反射项，不冒充完整 PBR。

## 常见错误

- 把位置向量当作法线。
- 法线、光源方向和观察方向混用世界、视图或局部空间。
- 非均匀缩放后直接复用顶点变换矩阵。
- 忽略叉积顺序，得到朝内的法线。

## 验收

- 所有法线长度接近 `1`，光照随面对光源的程度连续变化。
- 反弹满足反射公式，入射速度不会被错误地当成出射速度复用。
- 坡度阈值边界稳定，世界 Up 方向符合项目坐标约定。
- 非均匀缩放和模型旋转后，法线方向仍正确。
