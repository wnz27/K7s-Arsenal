# 从选题到成稿的写作工作流

## R — 原文

> "在写的时候，我先会搜索下这个题材有没有人写（基于 SEO 的方式去写作）……之后耗费半小时去罗列提纲……之后开始进入写作流程……戴着耳机不断重复某首很熟悉的旋律歌曲，这种无限循环的歌曲可以让我大脑很快进入一种写作的心流状态。"
> ——《写作的素材、排版、发布和推广》（马大伟）

> "写作的过程可分为脑力劳动和体力劳动。……动脑的事情其实不局限于时间和地点……而动手的事情宜集中时间统一处理。"
> ——《如何看待写作这件事》（于晓南）

## I — 自述

成稿不是从空白文档开始，而是从素材库开始。全流程七步：① 日常——阅读、思考、刷社区时把可写主题和关键点随手记进笔记，攒成素材库（"没得可写"多数是缺发现而不是没素材：培养"开始观察"的意识，专注倾听、活在当下）；② 选题——有整块时间时从库里挑一篇动笔；③ 调研——搜索该题材有没有人写、热门文章怎么写，找差异化角度，同时建立 SEO 意识；④ 提纲——半小时时间盒列提纲，把笔记里相关片段直接复制进来，不在构思阶段内耗；⑤ 配图——判断是否需要图，需要则先画再写；⑥ 成稿——用个人仪式（原书为单曲循环熟悉旋律）快速进入心流，写正文；⑦ 互链——与旧文建立链接，串联主题、延长读者停留。

时间分配上把写作切成两类劳动：脑力劳动（素材加工、构思、立意、大纲）放碎片时间（通勤、洗澡、做饭），体力劳动（码字、排版、修改、发布）集中整块处理。写作次序存在两种被认可的模式：瀑布式（先构思完再下笔，一气呵成）与边写边构思（初步立意后写中完善，水到渠成）——于晓南说"无所谓好坏，找到适合自己的节奏"；邱俊涛针对写长文/书则强调必须先列骨架自上而下，"随心所欲的写下去，基本上都收不住"。短文章可按个人节奏，长篇/书稿建议先骨架。

## A1 — 应用示例（原书案例）

**案例（作者工作流实录，马大伟）**：他的文章"耗费一小时到一周的都有"。具体序列：日常记录主题与关键点 → 动笔前先搜索题材与热门文章并浏览 → 半小时列提纲、复制笔记片段 → 思考是否需要配图（需要则先绘制）→ 单曲循环熟悉歌曲进入心流 → 写作并建立与旧文的互链。

**案例（作者亲历，于晓南）**：她描述写作前的"不需要准备更多"——"打开电脑，创建一个空白文档，然后就可以开始了"，构思立意在扫除、洗澡、通勤、做饭时完成，码字排版修改发布集中处理。

## A2 — 未来触发

**典型情境**：
1. 用户说"我有个选题，怎么把它写成文章"
2. 用户问"你们一般写文章的流程是什么"
3. 用户只有碎片时间，觉得没法写作
4. 用户写长文/系列文章时结构散乱收不住

**语言信号**：怎么写一篇文章 / 写作流程 / 没时间写 / 只有碎片时间 / 提纲怎么列 / how to turn an idea into an article / writing workflow / drafting process

**与相邻能力的区分**：还没想清楚写给谁、写什么 → article-positioning；写完要评估改进 → article-quality-review；写书级长文的工程管理 → book-writing-engineering。

## E — 执行步骤

**输入契约**：一个选题（必需；没有则先做第 0 步素材发现）、用户的可用时间形态。定位未做时先转 article-positioning。

0. **素材诊断**（无选题时）：区分"真没素材"（极少，建议先生活）与"缺发现"（常态）——给观察练习：接下来三天，每天记录一个工作中让你"咦"一下的瞬间。完成标准：素材库新增 ≥3 条。
1. **调研**：搜索同题材已有文章，浏览热门的前 3-5 篇。完成标准：写出一句话差异化定位（"已有文章都没讲清 X，本文讲 X"）。
2. **提纲**：设 30 分钟闹钟，列提纲并把笔记片段复制到对应小节。闹钟响即停。完成标准：提纲覆盖"总-分-总"骨架，每节有一句主旨。
3. **配图判断**：逐节问"这里一张图能否替代 200 字"。完成标准：列出必配图的清单（没有则明确"无需配图"）；需要图则先画再写。
4. **成稿**：集中整块时间写正文；写作次序按篇幅选——短文任选模式，长文先骨架后细化、从最熟悉的小节写起。完成标准：初稿完整（不追求完美），有结尾。
5. **互链**：检查正文提到的主题是否自己写过旧文，建立链接。完成标准：每篇旧文链接都注明锚文本与理由；无旧文可链则跳过。

**输出契约**：调研一句话定位 + 提纲 + 初稿 + （可选）互链清单。

## B — 边界

- 心流技巧（单曲循环）是个人经验，对部分人无效甚至干扰，鼓励用户找到自己的仪式。
- SEO 调研针对搜索引擎流量语境；AI 搜索时代其权重下降，但"差异化定位"价值不变——调研目的是不重复造轮子，不是迎合算法。
- 写作次序的两种模式原书内部有分歧，如实呈现，不替用户裁决；只在长篇/书稿场景给出"建议先骨架"的倾向。
- "半小时提纲"是防内耗的时间盒，不是质量标准；复杂题材可放宽但须设上限。
- 本卡只管成稿过程，发布相关转 prepublish-check 与 distribution-last-mile。
