# 发布前审读与脱敏把关

## R — 原文

> "发布前看三遍，第一遍看内容结构，第二遍看遣词造句，第三遍代入读者视角。基本上三遍过后，就没啥自己能改的了，可以找信任的他人看看，补充更多的第三方视角。"
> ——《如何看待写作这件事》（于晓南）

> "需要脱敏的信息包括但不限于：1. 涉及客户和项目的名称 2. 涉及公司机密的信息 3. 涉及同事的信息 4. 涉及所有用文字和图片的版权信息。"
> ——《如何评价一篇文章》（张凯峰）

## I — 自述

发布前两道关，缺一不可。

**第一道：审读。** 自审三遍，每遍焦点互斥——第一遍只看内容结构，第二遍只看遣词造句，第三遍代入读者视角。三遍之后进入收益递减区，自查停止（这就是"改到什么时候算完"的停机判据），转交信任的第三方补充视角。分工原理：错别字对作者极难（大脑自动纠错）、对读者极易，与"知识的诅咒"同构——所以低级错误的把关应交他人，作者自校重点放在读者无法代劳的结构与逻辑层。

**第二道：脱敏。** 对全文（含截图与图片）做全面排查，四类必查：① 客户与项目名称；② 公司机密信息；③ 同事个人信息；④ 所用文字与图片的版权信息。清单是"包括但不限于"的开放口径——所在行业有特殊合规要求的（如出版场景的地图审核：2018 年起书中地图须经相关机构审核）要在早期迭代就处理，避免成稿后大规模返工。

发布后还有两步：主动寻求社区反馈、把传播数据作为后续改进输入；隔段时间（三月半载）回顾旧文感知成长。

## A1 — 应用示例（原书案例）

**案例（作者亲历，邱俊涛）**："检查错别字对于作者来说，是一件非常困难的事情。而对于读者来说，则是一件很容易的事情。这跟知识的诅咒的道理一样。"——作者盲区是结构性问题，只能靠分工解决。

**案例（作者亲历，贺思聪）**：他的书稿含地图相关图片，2018 年国家新地图管理规定要求地图必须经审核才能出版。因采用迭代交付（每章完成即交编辑），"在书稿早期，就对内容进行刻意的控制，避免了大规模返工的情况"——合规前置的直接收益。

## A2 — 未来触发

**典型情境**：
1. 用户说"这篇要发了，帮我最后过一遍"
2. 用户问"发布前要检查什么"
3. 用户文章里提到公司项目/客户/同事，担心敏感信息
4. 用户无限改稿停不下手，问"改到什么时候算完"

**语言信号**：发布前检查 / 最后把关 / 脱敏 / 敏感信息 / 能发了吗 / pre-publish check / final review / sanitize / before publishing

**与相邻能力的区分**：文章还在质量改进阶段 → article-quality-review；只查排版格式 → chinese-tech-typography；发布后传播物料 → distribution-last-mile。

## E — 执行步骤

**输入契约**：已完成质量评估的成稿（必需）；用户的职业背景与组织合规要求（缺失时询问，特别是涉密行业）。若文章未经质量评估，先转 article-quality-review。

1. **三遍审读**：逐遍执行且每遍只查一个焦点——结构（骨架/详略/过渡）→遣词造句（语病/术语一致/错别字初筛）→读者视角（目标读者能否顺畅读完）。完成标准：每遍产出"问题清单 + 已修结论"，三遍后宣布自查停机。
2. **他人审校提示**：列出建议转交第三方的检查项（错别字、事实性错误、读者视角盲区）。完成标准：明确标注哪些项依赖第三方、在无人可委托时提示风险。
3. **脱敏扫描**：逐类排查并输出结果表——客户/项目名称（含截图、代码注释、URL、示例数据）；公司机密（内部数据、未公开策略、架构细节）；同事信息（姓名/言论/照片需授权）；版权（引用文字比例、图片来源与授权）。完成标准：四类逐项"通过/已处理/需用户决策"，需决策项不得代为放行。
4. **合规提示**：按用户行业补充提示（出版物的地图审核、医疗/金融内容监管等），并声明需核现行法规。完成标准：列出适用项与"需用户核实"标记。
5. **放行结论**：全部通过则给出可发布结论；有遗留项则列出放行前必办清单。

**输出契约**：三遍审读记录 + 脱敏四类检查表 + 放行结论（可发/待办清单）。

## B — 边界

- 脱敏清单是"包括但不限于"：行业与组织有特殊要求时必须让用户补充，不用本卡清单充当完整合规意见。
- 三遍审读后必须停机：原书明确三遍后"没啥自己能改的了"，继续自改是收益递减；用户的完美主义不是继续改的理由。
- 无人可委托第三方时，如实告知"错别字与盲区风险自负"，不假装 AI 能完全替代——AI 审读可分担，但"知识的诅咒"类盲区仍需真人视角。
- 组织内审批/报备流程原书未覆盖：在企业任职的用户需提醒其按组织流程报批。
- 出版合规（如地图审核）为 2018 年政策语境，执行时必须核对现行规定。
