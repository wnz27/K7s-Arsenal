# GLOSSARY.md — 《技术写作手册》共享术语词典（32 条）

> 阶段 3 产出。所有定义均为"作者本人的用法"，非字典定义。词条按主题分组；→ 表示关联能力。

## 动机与学习

- **写作驱动学习**（g01，王健）：写作是学习环节而非产出环节——把信息加工为知识的手段，价值在写完那一刻已兑现，作品可像 TDD 跑完的测试一样"丢掉"。≠ 常识以发布/阅读量论成败。→ cap-01/02
- **觉得不值**（g02，王健）：坚持不了写作的根因（非意志力）；解法是给事情设计持续快速的正反馈 + 降低难度。→ cap-01
- **信息/知识/智慧**（g03，王健引李光磊《知行合一》）：书只提供信息，经思考转化为知识，经行动内化为智慧；"书是一面镜子，我们读的看的其实是我们自己"。→ cap-02
- **长期主义 / 存款模型**（g04，李一鸣）：写文章一次付出持续收获，每篇文章是存款；前期数据低是本金少的结构使然，停更期仍有利息。是预期管理工具，非口号也非回报承诺。→ cap-01/13
- **写作是训练 / 发表是吸收的利器**（g05，李光毅）：写作像反复写代码练演讲，无顿悟时刻（性能问题没有单一真凶，只有十处各 500ms）；复述暴露模糊概念，博客是"无声的小伙伴"。→ cap-01/02
- **为自己而写**（g06，李光毅）：除非刻意运营公众号迎合流量，博客默认写给自己；读者反应不可预测，不应支配选题。→ cap-03/13
- **克制与沉浸**（g08，序言张凯峰）：持续写作两前提——有选择地信赖信息源、关闭侵蚀注意力的渠道（克制）；为心流刻意保留过渡性整块时间（沉浸）。→ cap-01/04

## 定位与质量

- **动笔前三问**（g10，张凯峰）：传达什么讯息 / 目标受众是谁 / 希望受众做什么；写前问、写完再问。→ cap-03
- **元问题**（g11，张凯峰）：媒体语境词——平台选题的隐性母题（TW 实例：怎样的公司/做什么/需要怎样的人）；使用时须抽象为"目标媒体的元问题清单"。→ cap-03/06
- **加分项**（g12，张凯峰）：争议性（抛砖引玉非博眼球）/ 总结性经验（"N 个 XXX"）/ 洞见性观点 / 故事性描述；非必需选项。→ cap-06
- **洞见**（g09，TW 语境）：既是平台名也是优质内容的操作性定义——透彻了解、引起共鸣但不带节奏、看透本质、"人无我有人有我精"。→ cap-06
- **总-分-总**（g13，张凯峰）：技术文章默认结构（开宗明义、清晰小标题、过渡流畅、结尾有力），是移动阅读注意力缺失前提下的读者效率设计。→ cap-06
- **表面功夫**（g14，张凯峰）：贬词褒用——排版与图片等阅读体验层的必要工序，做不好会真实伤害传播。→ cap-08
- **代入感 / 人称分工**（相关 p95/p96，张凯峰）：目的型写作焦点放读者身上、show don't tell；第一人称陈述观点、第二人称号召行动、第三人称客观陈述。→ cap-06

## 工作流与工程

- **脑力劳动/体力劳动**（g07，于晓南）：写作流程内部两种工序——构思立意（碎片时间）/ 码字排版发布（整块时间）。≠ 社会学劳动分类。→ cap-04
- **基于 SEO 的写作**（g22，马大伟）：动笔前搜索题材已有文章做差异化定位，正文与旧文互链提升可发现性与停留时长。→ cap-04/09
- **自上而下/自下而上**（g19，邱俊涛）：先章节骨架再逐步细化、从最熟悉处动笔；邱断言必需，于晓南认为与"边写边构思"无优劣——文集内部分歧，并置使用。→ cap-04/11
- **写文章 vs 写书**（g21，邱俊涛）：文章精简远离细节；书深入细节到"可依书自修"。→ cap-11
- **知识的诅咒**（g18，邱俊涛）：掌握知识后无法想象无知状态，故无法预判初学者困惑——唯一解法是找尽可能多的初学者试读；错别字检查同构（交给他人）。→ cap-07/11
- **迭代交付**（g20，贺思聪）：写书以章为迭代单位（约一月），每迭代交编辑预览；合规约束早期控制，避免大规模返工。→ cap-11

## 发布与传播

- **脱敏**（g15，张凯峰）：发表前对全文（含图）的四类信息清洗——客户项目名/公司机密/同事信息/版权；"包括但不限于"。≠ 数据安全的字段脱敏。→ cap-07
- **发布前看三遍**（g17，于晓南）：结构→遣词造句→读者视角，三遍后停机转他人审读——"改到何时算完"的停机判据。→ cap-07
- **最后一公里**（g16，张凯峰）：写完到传播之间的物料与动作——SEO URL + ≤70 字引文 + 引用图，及渠道交互；传播是写作流程的组成部分。→ cap-09
- **推广**（g23，马大伟）：各渠道发"简介+链接+配图"，好配图比标题更吸引人；无人响应先查标题与选题，不归咎质量。→ cap-09

## 翻译

- **理解原文优先**（g24，王静源）：翻译三步（阅读/理解/输出）中理解是源头；自己没弄明白就照搬，读者只会更混乱。→ cap-10
- **功能对等**（g25，王静源引尤金·奈达）：非文学翻译以读者为中心，优先级=准确 > 易读/易懂 > 还原风格；直译不合中文习惯时在保准确前提下意译。→ cap-10
- **直译/意译/翻译腔**（g26，王静源）：自由度谱系（逐字→直译→意译→解释翻译），非二元对立；直译保味易出翻译腔，意译融合易失风格。→ cap-10

## 心态与传播环境

- **反馈漏斗**（相关 p09，于晓南）：100 推送→20 点开→10 翻看→5 细读→1-2 反馈（个人观察口径）；没人看是常态，反馈者是真爱粉。→ cap-13
- **被误解是表达者的宿命 / 评论分量**（g30，于晓南+李光毅）：想的≠写的≠看的≠理解的，失真必然；勘误是职责，恶意曲解视心情处置；发言权平等≠专业分量相等。→ cap-13
- **数字枷锁/数字陷阱**（g27，李光毅）：创作焦虑的对象是媒介二次赋予的传播属性（点赞/阅读量），非内容实质；数值评判只反映大众偏好。→ cap-13
- **内容异化 / 信息茧房**（g28，李光毅）：数据从顺其自然生长变成创作第一要务即为异化；引波兹曼《技术垄断》、韩炳哲《同质化的恐怖》为思想背景。→ cap-13（参考）
- **双向筛选**（g29，李光毅）：看见≠理解（引约翰·伯格《观看之道》），知识壁垒从未消除，内容与受众互相选择天然正当；反对"人人能懂"的最低共同标准。→ cap-13
- **终极听众**（g31，董强译）：代码/文章同时面向机器与人，人类才是终极听众；可读性是第一维度，机器通过只是及格线。→ cap-05
- **平行结构 / 去除不必要的词**（g32，董强译 Strunk & White）：相似表述应有相似外形；每字每行都表达本意（不是要求短，是要求无冗余）。→ cap-05
